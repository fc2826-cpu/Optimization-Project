PROJECT OVERVIEW - NBA SCHEDULE OPTIMIZATION PROJECT

Starting from a given draft schedule, we imposed constraints to preserve the same game dates and the same home/away structure for each team.
We then optimized the schedule by minimizing teams’ travel distances. Using geographical coordinates, we computed travel distances for away games and formulated a mixed-integer optimization model that allows changing match pairings while keeping the season structure fixed.
The objective function minimizes the variance (least-squares) of total travel distances across teams, improving fairness and reducing extreme travel burdens.
Comparing the original and optimized schedules shows a more balanced distribution of travel distances, while maintaining a realistic and feasible NBA season schedule.
